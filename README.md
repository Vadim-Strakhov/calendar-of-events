# Calendar of Events

Простое консольное приложение для управления событиями с поддержкой напоминаний.

## Возможности

- ✅ Добавление, редактирование и удаление событий
- ✅ Установка приоритетов (low, medium, high)
- ✅ Система напоминаний с поддержкой времени и интервалов
- ✅ Автоматическое сохранение в JSON
- ✅ Интерактивная консоль с автодополнением
- ✅ Логирование всех операций

## Установка

### Требования
- Go 1.24.5 или выше

### Сборка из исходников

```bash
git clone https://github.com/Vadim-Strakhov/calendar-of-events.git
cd calendar-of-events
go mod download
go build -o calendar-of-events
```

## Запуск

```bash
./calendar-of-events
```

При первом запуске создается файл `calendar.json` для хранения данных.

## Команды

| Команда | Описание | Пример |
|---------|----------|--------|
| `add` | Добавить событие | `add "meeting" "Встреча с командой" "2026-01-15 14:00" "high"` |
| `list` | Показать все события | `list` |
| `update` | Обновить событие | `update "meeting" "Новая встреча" "2026-01-15 15:00" "medium"` |
| `remove` | Удалить событие | `remove "meeting"` |
| `reminder` | Установить напоминание | `reminder "meeting" "Не забудь про встречу!" "2026-01-15 13:30"` |
| `reminder-before` | Напоминание за время до события | `reminder-before "meeting" "Скоро встреча!" "30m"` |
| `cancel-reminder` | Отменить напоминание | `cancel-reminder "meeting"` |
| `show-reminders` | Показать активные напоминания | `show-reminders` |
| `log` | Показать историю команд | `log` |
| `help` | Показать справку | `help` |
| `exit` | Сохранить и выйти | `exit` |

## Форматы данных

### Приоритеты
- `low` - низкий
- `medium` - средний  
- `high` - высокий

### Даты и время
Поддерживаются различные форматы:
- `2025-01-15 14:00`
- `15.01.2025 14:00`
- `January 15, 2025 2:00 PM`
- `tomorrow 14:00`

### Длительность (для reminder-before)
- `30s` - 30 секунд
- `5m` - 5 минут
- `1h` - 1 час
- `2h30m` - 2 часа 30 минут
